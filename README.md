# Nexus Travel AI ✈

AI 驱动的旅行规划应用：通过中文对话生成个性化行程、目的地攻略与真实天气，支持行程管理与日历导出。Nuxt 4 全栈项目，前后端 + 数据库 + AI 管道 + 测试工程化完整闭环。

## 技术栈

| 分类 | 技术 |
| --- | --- |
| 前端框架 | Nuxt 4 + Vue 3.5 + Nitro 服务端 |
| AI 能力 | DeepSeek API |
| 数据层 | Prisma 7 + MariaDB |
| 天气数据 | Open-Meteo + Nominatim 地理编码，均免费 |
| 测试 | Vitest 单元测试 + Playwright 端到端测试 |
| 工程质量 | ESLint + Prettier、Git、模块化分层 |

## 功能

**AI 行程规划**
- 中文旅行助手实时对话，自动抽取目的地、天数、预算、人数、偏好并即时同步行程面板，抽取采用正则优先、LLM 兜底的防幻觉方案
- 一键生成包含时段、景点、简介、交通建议、花费、标签的逐日活动卡片，支持编辑与删除
- 生成结果目的地强一致校验，AI 输出自动净化，包括时段归一、数字转字符串、天数裁剪

**旅行管理**
- 行程保存、列表搜索与状态筛选，覆盖即将出发、旅行中、已结束、草稿四种状态
- 每日活动完成勾选与进度统计、行前打包清单、预算分配图
- 行程详情页：时间线视图/全部视图切换、活动详情弹窗、打印行程

**目的地攻略**
- AI 生成城市速览、美食、交通、文化礼仪、避坑提示
- 每日行程详解：基于已规划行程逐天生成"先去哪、怎么去、再去哪"的路线与交通衔接建议

**真实天气**
- 逐日天气预报：未来 16 天用实时预报，展示晴、多云、阴、雨等天气与降雨概率；更远日期显示历史气候常态，标注常有雨或基本无雨并注明数据来源
- 6 小时结果缓存，支持手动刷新；多城市目的地自动拆分定位

**其他**
- 一键导出 `.ics` 日历文件，每个活动对应一个日历事件，可直接导入系统日历
- 手机/平板/桌面全响应式适配

### 本地运行演示

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量（不配置也能演示，见下方 Mock 模式）
cp .env.example .env
# NUXT_DEEPSEEK_API_KEY=sk-xxx        # 需要真实 AI 时才填写
# NUXT_DATABASE_URL=mysql://user:password@localhost:3306/nexus_travel

# 3. 初始化数据库（需本地 MariaDB）
npm run db:generate
npm run db:migrate

# 4. 启动演示（两种模式任选）
npm run dev:mock   # 无需 DeepSeek 密钥，AI 返回固定演示数据，端口 3100
npm run dev        # 真实 DeepSeek AI，端口 3000
```

**建议演示路径**：首页 → AI 行程规划页输入"我想去大阪玩3天，预算5000，2个人"→ 点击"确认需求，生成行程"→ 中间面板实时出现 3 天行程、右侧概览同步 → 保存行程 → 我的旅行列表 → 查看行程 → 勾选活动、生成 AI 攻略（每日行程详解）→ 获取天气预报 → 导出日历。

**测试验证**：

```bash
npm test              # Vitest 单元测试 43 例（需求抽取/字段净化/攻略净化/合并逻辑）
npm run test:e2e      # Playwright 端到端主流程（自动启动 Mock 服务 + 独立测试库）
npm run lint          # ESLint 检查
```
